# Speekly — десктопный мессенджер

Electron (.exe для Windows) + Supabase (база, авторизация, realtime, аватарки) + GitHub (код и сборка).

## Что есть
- Чаты 1 на 1 с друзьями в реальном времени, «в сети» и время захода, галочки прочтения, поиск по чатам
- Фото, видео и файлы до 25 МБ (скрепка, кнопка с картинкой, вставка из буфера Ctrl+V), смайлы, просмотр фото, скачивание
- Друзья: поиск по нику, заявки, удаление
- Профиль: обложка и аватарка (в том числе анимированные), имя, о себе, несколько аккаунтов
- Настройки (все вкладки рабочие), русский и английский, вкладка «Помощь», режим «Невидимка»
- **Сквозное шифрование** текста и файлов (см. раздел «Шифрование» ниже)

## Обновление базы
Если `schema.sql` уже запускался раньше, выполни по порядку `supabase/migration_2.sql` (обложка, время захода, галочка) `supabase/migration_3.sql` (фото и файлы в чатах) и `supabase/migration_4.sql` (шифрование).
Синяя галочка у имени выдаётся вручную SQL-запросом из комментария в этом файле.

## Профиль
- Фото и обложка: можно GIF или WebP с анимацией (оригинал сохраняется без пережатия, до 4 МБ и 8 МБ). Обычные картинки сами обрезаются и сжимаются.
- Язык (русский / английский) переключается в Настройки → Внешний вид и на экране входа.
- «Смена профиля»: несколько аккаунтов на одном компьютере, переключение в один клик.

## 1. Supabase (один раз)
1. Создай проект на supabase.com.
2. SQL Editor → New query → вставь весь `supabase/schema.sql` → Run.
3. Authentication → Providers → Email → выключи **Confirm email** (иначе после регистрации придётся подтверждать почту).
4. Project Settings → API → скопируй **Project URL** и **anon public key**.
5. Впиши их в `src/config.js`. Anon-ключ публичный по дизайну, защита делается правилами RLS из schema.sql.

## 2. Запуск на компьютере
Нужен Node.js 20+.
```
npm install
npm start
```
F12 открывает консоль разработчика, если что-то не работает.

## 3. Сборка .exe
Локально: `npm run dist` → установщик появится в `dist/`.

Через GitHub: залей проект в репозиторий, затем либо запусти Actions → Build Windows exe → Run workflow (exe будет в Artifacts), либо поставь тег:
```
git tag v1.0.0
git push origin v1.0.0
```
Тогда установщик появится в Releases.

## Шифрование
Как работает: у каждого пользователя пара ключей ECDH P-256. Публичный ключ лежит в профиле, приватный остаётся на компьютере. Для каждой переписки из ключей двух людей получается общий ключ AES-256-GCM. Текст, имена файлов, типы и содержимое файлов шифруются на твоём компьютере, на сервер (Supabase) попадает только шифртекст. Всё сделано встроенным Web Crypto, без сторонних библиотек (`src/crypto.js`).

Что сервер всё же видит: кто с кем переписывается, когда и какого размера сообщения и файлы. Профили, аватарки и обложки не шифруются.

- **Резервная копия ключа.** При первом входе приватный ключ шифруется твоим паролем (PBKDF2, 250 000 итераций) и сохраняется в таблице `key_backups`. На другом компьютере достаточно ввести пароль, и история расшифруется. Пароль надёжнее делай длинным: от него зависит стойкость копии. Если забыть пароль и потерять компьютер, переписки прочитать будет нельзя.
- **Код безопасности.** Кнопка «E2E шифрование» в шапке чата показывает код, одинаковый у обоих собеседников. Сверь его лично или по звонку: совпал, значит никто не подменил ключи.
- **Выход из аккаунта** стирает ключ с компьютера. Если резервной копии нет, приложение предупредит.
- **Друг должен обновить приложение** и один раз войти в аккаунт, чтобы у него появился ключ. До этого писать ему нельзя (приложение не отправит открытым текстом).
- **Старые сообщения** (до шифрования) остаются в базе открытыми. Удалить их можно запросом `delete from public.messages where body not like 'e2e1:%';`

Проверка криптографии: `npm test`.
